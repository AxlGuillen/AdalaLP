# Servicios de ADALA

ADALA es una agencia internacional que opera entre **México, Estados Unidos y Canadá**.
No es exclusivamente una reclutadora ni una consultora: opera **tres líneas de servicio**.

## 1. Gestión Migratoria y Visados

Acompañamiento legal en trámites migratorios. Trámites atendidos:

| Trámite                                         | Identificador          |
| ----------------------------------------------- | ---------------------- |
| Visa de Trabajo                                 | `work-visa`            |
| Visa de Turista                                 | `tourist-visa`         |
| Perdón Migratorio                               | `immigration-waiver`   |
| Reunificación Familiar / Visa para Adulto Mayor | `family-reunification` |
| Naturalización                                  | `naturalization`       |
| Doble Nacionalidad                              | `dual-nationality`     |
| Petición por Matrimonio                         | `marriage-petition`    |

**Importante:** ADALA **no ofrece garantías de aprobación** de ninguna visa. Ofrece
preparación, integración documental y seguimiento profesional para elevar la
probabilidad de éxito conforme a la ley. Cualquier agente que responda sobre ADALA
debe reflejar esta limitación y no prometer resultados.

## 2. Certificación y Acreditación Laboral

Evaluación y certificación de competencias laborales con validez oficial, incluyendo
opciones de **titulación por experiencia** y de **nivel medio superior**. También se
certifican empleadores y se aplica reclutamiento ético.

## 3. Vinculación Empresarial y Turismo Corporativo

Organización de foros y misiones empresariales, además de logística de traslados,
hospedaje y conferencias/capacitaciones.

## A quién atiende

Tanto a **personas** como a **organizaciones**. Para empresas: certificación de
empleadores, reclutamiento ético y organización de eventos.

## Pilares operativos

Cumplimiento y legalidad, certificación y acreditación, reclutamiento ético,
gestión migratoria integral, vinculación y turismo corporativo, y transparencia
con seguimiento.
